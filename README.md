# The Recoded Coach — Claude Skills from *Dental Recoded*

You became a dentist. Then you got five other jobs.

*Dental Recoded* (free at [dentalrecoded.com](https://dentalrecoded.com)) shows practice owners how to build a practice that works beyond them, using the RECODE framework — Recognize, Establish, Coordinate, Operate, Decide, Expand.

This plugin turns the book into a coach that runs inside Claude. It doesn't summarize the book at you. It asks the book's questions, scores your answers the book's way, and shows you where your practice leans on you.

## Installation

In Claude Code:

```
/plugin marketplace add Jackiefred/recoded-coach
/plugin install recoded-coach
```

<details>
<summary>Alternative: install from a local copy</summary>

```bash
git clone https://github.com/Jackiefred/recoded-coach.git ~/.claude/plugins/recoded-coach
```

Then in Claude Code:

```
/plugin marketplace add ~/.claude/plugins/recoded-coach
/plugin install recoded-coach
```

</details>

## Skills

| Skill | Command | When to use |
|-------|---------|-------------|
| **Scorecard** | `/dental-scorecard` | Take the book's free 3-minute Scorecard: 18 questions, three for each step of RECODE, producing your Recode Score out of 100, the shape of your practice across the six steps, and the places to look first. Start here. |
| **Recognize** | `/recognize` | Where your practice leans on you. Runs Chapter 1's Owner Dependency Map and Chapter 2's Five-Day Test (the Hallway Tally). |
| **Establish** | `/establish` | What the practice knows, and where it lives. Runs Chapter 5's Memory Test and drafts your first Brain page from what it finds. |
| **Coordinate** | `/coordinate` | Which jobs a team of helpers could carry. Runs Chapter 6's Coverage Test across all sixteen departments. |
| **Operate** | `/operate` | How much runs from one clear instruction. Runs Chapter 7's One-Instruction Test (the Instruction Trace) and Chapter 8's Away Test. |
| **Decide** | `/decide` | What stays yours, and what needs your approval. Runs Chapter 13's Rules Test: do your rules travel? |
| **Expand** | `/expand` | How it fits the tools you already own. Runs Chapter 14's Systems Test: how many islands do you own? |

The path the book lays out: take the Scorecard, work the step that leans on you most, then take the Scorecard again and watch the number move.

## Straight talk

The Scorecard is not a diagnosis, a grade or a prediction, and there is no passing score. It shows where to look first. Nobody can promise your results, and we don't.
